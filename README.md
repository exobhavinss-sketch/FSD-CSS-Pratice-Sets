# HTML, CSS & JavaScript Practice Repository

This repository contains a complete set of beginner-to-intermediate front-end practice exercises covering HTML, CSS, and JavaScript fundamentals. It is organized into multiple practice sets to help build strong web development skills step by step.

## Practice Sets Overview

### CSS Pratice Set 1
- Basic CSS styling
- Element selectors and class selectors
- Text formatting and layout basics

### CSS Pratice Set 2
- More styling practice
- Box model understanding
- Margins, padding, borders, and spacing

### CSS Pratice Set 3
- Layout and color design practice
- Card-like sections and visual structure
- Improved styling consistency

### CSS Pratice Set 4
- Intermediate CSS concepts
- Positioning and alignment
- UI section design and cleaner composition

### CSS Pratice Set 5
- Responsive styling fundamentals
- Structured page sections
- Better control over spacing and typography

### CSS Pratice Set 6
- Advanced practice with layout planning
- More complex visual arrangement
- Grid and alignment patterns

### CSS Pratice Set 7
- Design-focused styling in detail
- Building polished sections and blocks
- Practical CSS composition exercises

### CSS Pratice Set 8
- UI refinement and design practice
- More realistic webpage structure
- Styling creativity and consistency

### CSS Pratice Set 9
- Responsive web design with media queries
- Breakpoint-based styling for different screen sizes
- Color changes triggered by viewport width
- Practice with layout centering and adaptive design

### CSS Pratice Set 10
- CSS animation fundamentals
- Spinner/loader design using border styling
- Rotation animation with keyframes
- Centering and visual effects in a simple layout

### HyperText Markup Language Pratice
- HTML structure exercises
- Semantic markup practice
- Images, text formatting, and content organization
