## Learning Goals

By completing these exercises, you will practice:

- HTML page structure and semantic elements
- CSS selectors, styling, and layout techniques
- Box model and positioning
- Typography, colors, spacing, and design balance
- Building simple but structured webpages
- Improving visual presentation and responsiveness

## How to Use This Repository

1. Open any folder in the project.
2. Open the `index.html` or relevant HTML file in a browser.
3. Review the corresponding CSS file to understand the styles.
4. Edit the HTML/CSS to practice and experiment with design changes.

## Recommended Workflow

- Start from Set 1 and move upward gradually.
- Practice understanding the structure before modifying styles.
- Try recreating designs from memory after reviewing the code.
- Keep experimenting with colors, spacing, and layout adjustments.

## Tools Needed

- Any modern web browser
- A code editor such as VS Code
- Basic knowledge of HTML and CSS
